# Use Input Bridge on-screen keys

[Input Bridge](https://inputbridge.net/) is a separate Android app for
on-screen keyboard and mouse buttons. WeHavePhones does not include it. Install
it yourself and set it up as usual, then:

1. In Input Bridge, keep **Download** as the root folder and tap **Copy
   installer to root folder**. You do not need to run its `install.bat`:
   WeHavePhones starts Input Bridge's `ib.exe` itself.
2. We recommend turning off **Enable XInput** in Input Bridge's touch
   controls. That option loads Input Bridge's own DLL into the game. Keyboard
   and mouse buttons do not need it.
3. In WeHavePhones **Settings**, turn on **Disable virtual gamepad**, so
   WeHavePhones' touch controls do not sit under your Input Bridge buttons, and
   **Start Input Bridge** below it.

Then press **Play**.
